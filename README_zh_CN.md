# 图片悬浮预览

双击文档中的图片，或单击数据库中的图片，让图片直接悬浮在页面上。可同时钉住多张，不打断编辑。

## 功能

* 替代编辑器双击预览，以及数据库资源列的单击预览
* 图片本身悬浮，缩放会改变图片大小
* 切换时尽量保持当前宽度；只有会超出屏幕时才缩小，并尽量保持中心
* 放大、缩小、实际大小、适应窗口
* 左右旋转、水平/垂直翻转
* 拖拽移动图片
* 滚轮缩放，`Ctrl` / `Shift` + 滚轮平移
* 显示图片标题和文件名，点击可复制
* 工具栏或右键可复制文件、复制为 PNG

## 一些技巧

* 如果不想查看文档或数据库中的全部图片，可以按紧 `Ctrl` 再打开，范围仅当前编辑器/视图里已加载的图片
* `Esc` 关闭，`←` `→` 或 `A` `D` 切换
* `R` / `L` 旋转，`H` / `V` 翻转，`0` 适应窗口，`1` 实际大小
* 双击图片在适应窗口和上次缩放之间切换
* 右键可复制、导出、打开文件位置，以及显示/隐藏按钮
