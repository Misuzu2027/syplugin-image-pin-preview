# 图片悬浮预览

双击文档中的图片，或单击数据库中的图片，让图片直接悬浮在页面上。可同时钉住多张，不打断编辑。

## 功能

* 替代编辑器双击预览，以及数据库资源列的单击预览
* 图片本身悬浮，缩放会改变图片大小
* 桌面端切图尽量保持图片宽度和中心。手机端切图时翻页键停在原位，下一张图片在底栏上方等比显示。把多图预览缩到最小时，底栏只保留左右翻页键；放大后会恢复图片信息和工具入口。
* 放大、缩小、实际大小、适应窗口
* 左右旋转、水平/垂直翻转
* 拖拽移动图片
* 滚轮缩放，`Ctrl` / `Shift` + 滚轮平移
* 手机上可双指缩放；一指按住图片，另一指可以点在图外
* 手机上双击想看的位置可放大到初始尺寸的两倍，再次双击复位。点底栏右侧箭头可展开或收起第三行工具，「更多操作」在这一行末尾。每张悬浮图独立记住展开状态，直到关闭。
* 支持系统分享的 Android 和鸿蒙客户端可长按本地图片分享原文件。Android 还可选择「保存到相册」。iOS 上选择「导出」即可打开系统分享面板。
* 手机上的图片详情默认半屏。上拖把手展开全屏，下拖恢复半屏，再下拖关闭。点详情中的值可复制。
* 显示图片标题和文件名，点击可复制
* 工具栏或右键可复制文件、复制为 PNG
* 在图片右键菜单或悬浮预览的「更多操作」中选择「设为隐私图片」。同一资源在文档、数据库和预览中都会遮挡。点「解锁查看」只临时显示当前这一处，切图、关闭预览或离开页面后恢复遮挡。隐私标记会保存，蒙版用于浏览时防窥，原文件的访问权限仍由思源管理。

## 一些技巧

* 如果不想查看文档或数据库中的全部图片，可以按紧 `Ctrl` 再打开，范围仅当前编辑器/视图里已加载的图片
* 按住 `Alt`（macOS 为 Option）再用原来的手势，会打开思源官方预览。文档是双击，数据库和预览模式是单击。隐私图片通过插件的悬浮预览打开，官方预览里翻到隐私图片时也需要解锁。
* `Esc` 关闭，`←` `→` 或 `A` `D` 切换
* `R` / `L` 旋转，`H` / `V` 翻转，`0` 适应窗口，`1` 实际大小
* 桌面端双击图片可在适应窗口和上次缩放之间切换
* 右键可复制、导出、打开文件位置，以及显示/隐藏按钮
