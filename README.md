# Image Pin Preview

Double-click images in the editor, or click images in a database, to pin the image itself above the page. Multiple images can stay pinned while you keep editing.

## Features

* Replaces the native editor double-click preview and database asset-column click preview
* The image floats on its own; zoom changes the image size
* On desktop, switching images keeps the image centered. On mobile, the arrows stay under your finger as the next image fits above the footer. At the smallest gallery size, only the two arrows remain in the footer. Zoom in to bring back image information and tools.
* Zoom, actual size, fit
* Rotate and flip
* Drag to move the image
* Mouse wheel to zoom; `Ctrl` / `Shift` + wheel to pan
* On mobile, pinch to zoom; one finger can stay on the image while the other is outside it
* On mobile, double-tap a detail to zoom to twice the initial size. Double-tap again to return. Tap the chevron to expand or collapse the third row of tools, including **More actions**. Each pinned image remembers this choice while open.
* Long-press a local image to share the original on supported Android and HarmonyOS clients. Android also offers **Save to gallery**. On iOS, choose **Export** to open the system share sheet.
* Mobile image details open at half height. Drag the handle up to expand, down to return to half height, and down again to close. Tap a detail value to copy it.
* Shows the image title and file name; click to copy
* Copy file or copy as PNG from the toolbar or context menu
* Choose **Mark as private** in the image context menu or the floating preview’s **More actions** menu. All uses of the same resource in documents, databases, and previews are obscured. **Unlock to view** reveals only that instance until you switch images, close the preview, or leave the page. The mark is saved for future sessions. SiYuan still manages access to the original file.

## Tips

* Hold `Ctrl` when opening to preview only images already loaded in the current editor or database view
* Hold `Alt` (Option on macOS) and use the usual gesture to open SiYuan’s native preview. Double-click in the editor, or single-click in a database or preview mode. Private images open in the floating preview and also require unlocking if you navigate to one within SiYuan’s native preview.
* `Esc` closes; `←` `→` or `A` `D` switches images
* `R` / `L` rotate, `H` / `V` flip, `0` fit, `1` actual size
* On desktop, double-click the image to toggle fit and the last zoom
* Right-click for copy, export, reveal in folder, and button visibility
